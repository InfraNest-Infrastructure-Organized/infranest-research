# Security

Found a security problem in this code or in InfraNest? Please report it privately, as described in
[infranest.io/.well-known/security.txt](https://infranest.io/.well-known/security.txt), not as a public issue.

This scanner only reads public DNS answers and makes one TLS handshake per site. If you think it behaved
differently towards your systems, write to [research@infranest.io](mailto:research@infranest.io).
